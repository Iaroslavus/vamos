# Vamos v2 — испанский по жизненным ситуациям

## Обещание пользователю
**Заговорите с первого дня. Через 7 дней — закажете кофе, купите продукты и спросите дорогу.**
Дальше — новые ситуации и уровни, вплоть до свободного владения (C2).

## 7 принципов (по ним проверяем каждое решение)
1. **Сначала знакомство — потом проверка.** Ни одного упражнения на слово или фразу, которые пользователь ещё не видел и не слышал.
2. **Фразы важнее отдельных слов.** ~60% учебных единиц — готовые фразы. Слова изучаются внутри фраз, которые реально говорят.
3. **Ситуация — единица обучения.** Тема = место или задача из жизни («В кафе», «Спортзал») + список «смогу…».
4. **Говорить с первого урока.** В каждом уроке минимум 2–3 фразы произносятся вслух с проверкой.
5. **Грамматика по требованию.** К фразе — короткая подсказка «Почему так?» (1 экран). Отдельные грамматические темы — с A2.
6. **Повторение без усилий.** Общий алгоритм FSRS + личные словники (папки) для своих целей.
7. **Просто.** Один экран — одно действие. Урок ≤ 7 минут. Ни одного экрана без понятной следующей кнопки.

## Структура обучения
```
Уровень (A1…C2)
└─ Категория (Еда и напитки, Покупки, Город, Спорт и здоровье, Переезд…)
   └─ Тема (В кафе) — цели «смогу…»
      ├─ Уроки 1–4 (по 6–8 новых единиц)
      └─ Сценка — финальный диалог всей темы (сначала по сценарию, позже с ИИ)
```
**Спираль:** одна ситуация возвращается на разных уровнях с новыми задачами.

| Ресторан | Что умеет пользователь |
|---|---|
| A1 | заказать блюдо и напиток, попросить счёт |
| A2 | особые пожелания (без лука, аллергия), простая жалоба |
| B1 | спросить рекомендацию, забронировать по телефону, вежливо поспорить о счёте |
| B2 | обсудить кухню, написать отзыв, решить конфликт |
| C1 | гастрономическая культура регионов, тонкости вежливости |
| C2 | идиомы, юмор и ирония за столом, региональные особенности речи |

## Урок: 6 шагов «Узнать → Понять → Вспомнить → Сказать»
| Шаг | Что происходит | Упражнения | ≈ время |
|---|---|---|---|
| 1. Знакомство | Карточка каждой новой единицы: аудио (обычно/медленно), перевод, разбор фразы по частям, подсказка произношения кириллицей (A1–A2), пример ситуации, «+ В словник» | intro | 1,5 мин |
| 2. Узнавание | Лёгкое: услышать и выбрать, найти пары | listen_select, match_pairs, select_translation | 1,5 мин |
| 3. Сборка | Собрать фразу из частей, вставить пропуск | build_sentence, fill_gap | 1,5 мин |
| 4. Вспоминание | С русского на испанский | type_translation | 1 мин |
| 5. Сказать вслух | 2–3 фразы с проверкой произношения | speak_repeat | 1 мин |
| 6. Мини-диалог | 4–6 реплик ситуации: пользователь выбирает или произносит свою реплику | dialog | 1 мин |

В конце — работа над ошибками (экран «А теперь давайте поработаем над ошибками»), итог, новые единицы уходят в FSRS.

**Объём урока:** 6–8 новых единиц (4–5 фраз + 2–3 слова). Отдельных слов вне фраз — не больше 3.
**Шаги генерируются автоматически** из списка единиц урока. Автор контента пишет только единицы и мини-диалог — это в разы ускоряет производство курса.

## Первая неделя: «Заговори за 7 дней»
Рекомендованный старт для новичков. 10 минут в день. К концу — ~45 фраз в активе.

| День | Тема | Смогу… |
|---|---|---|
| 1 | ¡Hola! Знакомство | поздороваться, назвать имя, спросить, как дела, поблагодарить |
| 2 | В кафе | заказать напиток, спросить цену, попросить счёт |
| 3 | Числа и цены | понять цену на слух, назвать количество, спросить «сколько стоит?» |
| 4 | В магазине | спросить, есть ли товар, попросить пакет, оплатить картой |
| 5 | Как пройти? | спросить дорогу, понять «направо / налево / прямо» |
| 6 | В ресторане | забронировать стол, заказать, сказать об аллергии |
| 7 | Первый разговор | связный диалог из всех тем недели + итоговая сценка |

**Онбординг = начало Дня 1.** В первые 3 минуты пользователь слышит и произносит «Hola, me llamo …» — это главный вау-момент.

## Словники (личные папки)
- **Системные:** «Избранное», «Сложные» (автоматически — где часто ошибки), по каждой пройденной теме.
- **Свои папки:** создать, переименовать, выбрать цвет. Пример: «Для переезда», «Спортзал», «Работа».
- **Добавить из любого места:** карточка знакомства, итог урока, мини-диалог, долгое нажатие на слово.
- **Повторить папку:** карточками или быстрыми упражнениями. Алгоритм FSRS общий — одна карточка на единицу, в каких бы папках она ни лежала.
- **Позже:** свои слова и фразы (ввод вручную + перевод и озвучка автоматически), поделиться папкой.

## Произношение
- **v1 (на устройстве, бесплатно):** распознавание речи (es-ES) → сравнение с эталоном по словам → каждое слово зелёное / жёлтое / красное, процент, подсказка по проблемному слову, кнопка «Слушать образец». Честно в интерфейсе: проверяется понятность, а не акцент.
- **v2 (Plus):** оценка по звукам через облачный сервис (точность, беглость, полнота, ударение) — через Supabase Edge Function.

## Навигация
**Сегодня** · **Темы** · **Словник** · **Профиль**
- Сегодня — одна главная кнопка «Продолжить», повторение, произношение, мои темы, серия.
- Темы — каталог по уровням и категориям, поиск.
- Словник — папки и все изученные единицы.
- ИИ-собеседник — позже, внутри темы как «Сценка с ИИ».

## Что будем продавать (после перестройки)
- **Бесплатно:** вся первая неделя, 1 новая тема в неделю, повторения, словники (до 3 своих папок), произношение v1.
- **Plus:** все темы A1–C2, подробная оценка произношения, ИИ-сценки, безлимит папок, офлайн-режим.
- Пейвол показываем **после Дня 3** — когда человек уже говорит и чувствует результат, а не на старте.

## Метрики успеха
- Новые пользователи, произнёсшие первую фразу в первые 3 минуты — цель > 70%.
- Завершили День 1 / День 3 / День 7.
- Retention D1 / D7 / D30.
- Единиц в словниках на активного пользователя.
