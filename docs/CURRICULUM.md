# Курс Vamos v2: темы A1 → C2

Ориентиры: CEFR, Plan Curricular del Instituto Cervantes (PCIC), формат DELE.
Аудитория: русскоязычные — путешествия, переезд в Испанию и Латинскую Америку, работа.

## Грамматика «в фразах»
Грамматика появляется сначала внутри фраз темы, потом — короткой подсказкой «Почему так?», с A2 — отдельной мини-темой.
- **A1:** ser / estar, род и артикли, presente (частые глаголы), gustar, hay, quisiera как готовая фраза, вопросы.
- **A2:** pretérito perfecto, indefinido, imperfecto (база), ir a + inf., местоимения-дополнения, imperativo.
- **B1:** противопоставление прошедших, futuro, condicional, presente de subjuntivo, косвенная речь.
- **B2–C2:** см. предыдущую версию курса; subjuntivo во всех временах, стилистика, регистры.

## Формат контента v2
Три вида файлов: общая **библиотека единиц**, **темы**, **уроки** (+ диалоги внутри урока/темы).

Строки для ученика — словари `{ "ru", "uk", "en" }`: перевод `tr`, дословная фраза `literal`, подсказка `say`, пояснения `note` и `why`, заголовки `title`, цели `can_do`, реплики npc и `parts[].tr`.
Язык берётся из интерфейса. Если перевода нет, подставляется английский. Невычитанные uk и en помечаются `"draft_i18n": true`.

`parts[].tr` — дословный перевод части, с родом, числом и падежом этого испанского слова. Смысл всей фразы сюда не подставляют: у «buenos días» días — это «дни / дні / days», не «утро / ранок / morning».
`tr` — естественный перевод фразы: «доброе утро», «добрий ранок» или «доброго ранку», «good morning».
`literal` — дословный перевод всей фразы. Поле пишут только когда он не совпадает с `tr`. Если дословно и по смыслу одно и то же, поле опускают. Под чипами частей урок показывает «буквально: …», только если `literal` есть.

### Единица (content/items/a1/cafe.json — массив)
```json
{
  "id": "cafe.cafe_con_leche",
  "type": "phrase",
  "es": "Un café con leche, por favor",
  "tr": {
    "ru": "Кофе с молоком, пожалуйста",
    "uk": "Кава з молоком, будь ласка",
    "en": "A coffee with milk, please"
  },
  "parts": [
    { "es": "un café", "tr": { "ru": "кофе", "uk": "кава", "en": "a coffee" } },
    { "es": "con leche", "tr": { "ru": "с молоком", "uk": "з молоком", "en": "with milk" } },
    { "es": "por favor", "tr": { "ru": "пожалуйста", "uk": "будь ласка", "en": "please" } }
  ],
  "say": {
    "ru": "ун кафЕ кон лЕче, пор фавОр",
    "uk": "ун кафЕ кон лЕче, пор фавОр",
    "en": "oon ka-FEH kon LEH-cheh, por fa-VOR"
  },
  "note": {
    "ru": "В Испании так заказывают кофе у стойки.",
    "uk": "В Іспанії так замовляють каву біля стійки.",
    "en": "In Spain this is how you order coffee at the counter."
  },
  "why": null,
  "level": "A1",
  "variant": "both",
  "audio": {
    "source": "tts",
    "es": "items/a1/cafe/cafe_con_leche.es.normal.m4a",
    "latam": "items/a1/cafe/cafe_con_leche.mx.normal.m4a",
    "slow": {
      "es": "items/a1/cafe/cafe_con_leche.es.slow.m4a",
      "latam": "items/a1/cafe/cafe_con_leche.mx.slow.m4a"
    },
    "parts": []
  },
  "tags": ["cafe", "pedir"],
  "draft_i18n": false
}
```
- `type`: `word` | `phrase`. `say` — подсказка произношения буквами языка ученика, только A1–A2. Для ru и uk это кириллица, для en — латинская запись. Выше A2 поле `say` равно `null`.
- `parts[].tr` дословный. Пример, где дословное чтение не равно естественному `tr`:

```json
{
  "es": "buenos días",
  "tr": { "ru": "доброе утро", "uk": "добрий ранок", "en": "good morning" },
  "literal": { "ru": "добрые дни", "uk": "добрі дні", "en": "good days" },
  "parts": [
    { "es": "buenos", "tr": { "ru": "добрые", "uk": "добрі", "en": "good" } },
    { "es": "días", "tr": { "ru": "дни", "uk": "дні", "en": "days" } }
  ]
}
```

- `variant`: `es` | `latam` | `both`. Если различается — две единицы с пометкой.
- `audio.source`: `tts` или `human`. Запись диктора (`human`) не заменяется генерацией. `es` и `latam` — обычная скорость (es-ES и es-MX), `slow` — та же пара, уже произнесённая медленно. Старый вид `{ "es": "путь", "latam": null }` по-прежнему читается как обычная скорость.
- Одна единица может использоваться в нескольких темах (без дублей).

### Тема (content/topics/a1/cafe/topic.json)
```json
{
  "id": "a1.cafe",
  "level": "A1",
  "category": "food",
  "title": {
    "ru": "В кафе",
    "uk": "У кафе",
    "en": "At a café"
  },
  "icon": "cup",
  "can_do": [
    { "ru": "Заказать напиток", "uk": "Замовити напій", "en": "Order a drink" },
    { "ru": "Спросить цену", "uk": "Запитати ціну", "en": "Ask the price" },
    { "ru": "Попросить счёт", "uk": "Попросити рахунок", "en": "Ask for the bill" }
  ],
  "lessons": ["a1.cafe.l1", "a1.cafe.l2", "a1.cafe.l3"],
  "scene": "a1.cafe.scene",
  "starter_day": 2
}
```
У урока и сценки заголовок тоже словарь `title`, в тех же трёх языках.

### Урок (content/topics/a1/cafe/l1.json)
```json
{
  "id": "a1.cafe.l1",
  "topic": "a1.cafe",
  "title": {
    "ru": "Заказываем кофе",
    "uk": "Замовляємо каву",
    "en": "Ordering coffee"
  },
  "items": ["cafe.hola_buenos_dias", "cafe.cafe_con_leche", "cafe.un_te", "cafe.cuanto_es", "cafe.para_llevar", "cafe.aqui"],
  "speak": ["cafe.cafe_con_leche", "cafe.cuanto_es"],
  "dialog": {
    "lines": [
      { "who": "npc", "es": "¡Hola! ¿Qué le pongo?", "tr": { "ru": "Здравствуйте! Что вам?", "uk": "Добрий день! Що вам?", "en": "Hello! What can I get you?" } },
      { "who": "user", "target": "cafe.cafe_con_leche", "options": ["cafe.cafe_con_leche", "cafe.un_te", "cafe.cuanto_es"] },
      { "who": "npc", "es": "¿Para tomar aquí o para llevar?", "tr": { "ru": "Здесь или с собой?", "uk": "Тут чи із собою?", "en": "Here or to go?" } },
      { "who": "user", "target": "cafe.para_llevar", "options": ["cafe.para_llevar", "cafe.aqui"] }
    ]
  },
  "overrides": []
}
```
Шаги урока (знакомство → узнавание → сборка → вспоминание → сказать → диалог) **генерирует движок** из `items`, `speak` и `dialog` на языке ученика. Варианты ответа в `select_translation` — переводы того же языка. `overrides` — ручные упражнения, если автогенерация не подходит; их `prompt` тоже словарь языков.

## Производство контента
1. Список тем и целей «смогу…» — по PCIC и здравому смыслу (что реально нужно в ситуации).
2. Скрипт генерирует черновик темы через LLM по схеме выше → валидация Zod → `draft: true`.
3. **Вычитка носителем — обязательно** (ошибки в языке убивают доверие и рейтинг).
4. TTS-аудио двумя голосами (Испания, Латинская Америка), обычная и медленная скорость — заранее, файлы в Supabase Storage.
5. Ориентир: тема ≈ 25–30 единиц, 3–4 урока + сценка, ~30 минут обучения.
