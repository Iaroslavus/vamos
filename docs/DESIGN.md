# Дизайн Vamos

Макеты пяти ключевых экранов — на дизайн-холсте Vamos в Claude (Главная, Урок, ИИ-собеседник, Прогресс, Подписка).
Экран урока там интерактивный: можно собрать фразу и нажать «Проверить».

## Принципы
1. **Одно главное действие на экране** — большая коралловая кнопка внизу, в зоне большого пальца.
2. **Прогресс всегда виден** — серия, цель дня, процент уровня.
3. **Каждое действие отвечает движением и вибрацией** — приложение «живое».
4. **Ничего лишнего** — 4 вкладки: Учиться, Диалог, Прогресс, Профиль.

## Экраны MVP
1. **Онбординг** (5 шагов): цель (путешествия / работа / переезд / DELE) → текущий уровень (или тест 3 мин) → минут в день (5/10/20/30) → первое мини-задание (вау-момент: собрал фразу и услышал её) → пейвол с пробным периодом.
2. **Главная — путь**: змейка узлов по блокам, текущий узел пульсирует, карточка цели дня, серия и XP.
3. **Урок**: прогресс-бар, сердечки (только для бесплатных — мягкое ограничение), упражнение, кнопка «Проверить», нижний лист с результатом.
4. **Итог урока**: конфетти, +XP, точность, время, новые слова → «Дальше».
5. **Повторение**: карточки FSRS с самооценкой (Снова / Трудно / Хорошо / Легко).
6. **Диалог с ИИ**: ролевые сценарии, исправления жёлтыми карточками, подсказки-чипы, голосовой ввод.
7. **Прогресс**: уровни A1–C2, навыки (словарь, грамматика, аудирование, разговор), тест уровня в формате DELE.
8. **Профиль и настройки**: напоминания, цель дня, вариант испанского (Испания / Латам), подписка.
9. **Пейвол**: годовой план выделен, 7 дней бесплатно, честный текст об отмене.

## Иконки и иллюстрации
Линейные иконки (Phosphor или Lucide, stroke 2.2). Маскот-солнце (Sol) в Lottie для празднований и пустых состояний.
