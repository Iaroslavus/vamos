# План перестройки Vamos v2

Цель: превратить приложение из «уроков A1» в **курс по жизненным ситуациям**, где человек заговаривает в первый день, а через неделю справляется в кафе, магазине и на улице.

Что сохраняем из уже сделанного: дизайн-систему, компоненты, все типы упражнений, проверку ответов, стор урока, экран итога, работу над ошибками, Supabase, вход, синхронизацию прогресса, серию и XP, FSRS.
Что меняем: модель контента, порядок шагов урока, навигацию, главную. Что добавляем: темы, знакомство с единицами, мини-диалоги, произношение, словники.

Монетизация (бывшая Фаза 5) и ИИ-собеседник (Фаза 6) — **после** перестройки.
Если задачи 4.3–4.5 (экран повторения) не сделаны — не делайте их отдельно: они входят в R10.

## Как работать (обязательно)
- Одна задача → новый чат агента → PR → проверка в симуляторе → `ship` → следующая.
- Каждый промпт начинается со строки «Следуя @.cursor/rules/40-definition-of-done.mdc и @.cursor/rules/20-content.mdc».
- Перед задачей: `git checkout main && git pull && npm install`, `gh pr list` пустой.

```
Следуя @.cursor/rules/40-definition-of-done.mdc и @.cursor/rules/20-content.mdc:
```

## R2. Генератор шагов урока
```
Следуя @.cursor/rules/40-definition-of-done.mdc и @.cursor/rules/20-content.mdc:
ветка feat/lesson-generator. src/features/lesson/generator.ts: Lesson v2 → массив шагов
intro → recognize → build → recall → speak → dialog (см. @docs/PRODUCT.md, раздел «Урок»).
- intro: по одной карточке на каждую новую единицу.
- recognize: listen_select / match_pairs / select_translation, дистракторы из того же урока
  и уже пройденных единиц темы.
- build: build_sentence для фраз (плитки из parts + 1–2 лишних), fill_gap.
- recall: type_translation для 2–3 единиц.
- speak: speak_repeat для items из lesson.speak.
- dialog: из lesson.dialog.
- overrides добавляются/заменяют шаги по индексу.
Детерминированно по seed. Тесты: ни одно упражнение не использует единицу до её intro;
длина урока 18–26 шагов; одинаковый seed → одинаковый результат. Без UI. Открой PR.
```

```

   автоматически: Избранное, Сложные (единицы с ≥ 2 ошибками за 14 дней), по пройденным темам.
2. Вкладка «Словник» как на макете: «Повторить всё · N к повторению», список папок
   (иконка, название, количество, сколько к повторению), «+ Новая папка»; экран папки —
   список единиц с озвучкой, удаление, перенос.
3. Нижний лист «Добавить в словник» из IntroStep, итога урока и DialogStep (долгое нажатие).
4. Повторение папки или всего: карточки FSRS (переворот, 4 оценки с интервалами)
   и режим «Быстрое повторение» упражнениями (верно сразу → Good, после ошибки → Hard,
   неверно → Again). Офлайн-очередь через repository. Тесты. Открой PR.
```

## Как понять, что перестройка удалась
- Новый пользователь произносит первую фразу в первые 3 минуты.
- День 1 проходится за 8–10 минут без единого непонятного экрана.
- Ни одно упражнение не спрашивает то, чего не было в знакомстве.
- Можно сохранить фразу в свою папку и повторить папку отдельно.
- Дайте пройти День 1–3 двум-трём знакомым без объяснений и посмотрите, где они застревают.
