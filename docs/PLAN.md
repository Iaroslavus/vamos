# План разработки Vamos в Cursor

Сроки рассчитаны на одного человека с Cursor, 20–30 часов в неделю.
**MVP (A1–A2, iOS + Android) — ~10 недель. Полный курс до C2 — ещё 9–12 месяцев**, в основном за счёт контента.

Как пользоваться: откройте новый чат Cursor (режим Agent), вставьте промпт задачи. После каждой задачи — проверка на телефоне и `git commit`.

---

## Фаза 0. Каркас проекта (день 1)

**0.1 Создание проекта**
```
Создай в текущей папке проект Expo с TypeScript и expo-router (последний стабильный SDK),
не удаляя папки .cursor, docs и src/theme. Установи: react-native-reanimated, moti,
lottie-react-native, expo-haptics, expo-audio, zustand, @tanstack/react-query,
@supabase/supabase-js, react-native-purchases, i18next, react-i18next, ts-fsrs, zod,
@expo-google-fonts/bricolage-grotesque, @expo-google-fonts/manrope.
Настрой ESLint, Prettier, TypeScript strict, алиас @/ на src/.
Структуру папок сделай по @.cursor/rules/00-project.mdc. Проверь, что `npx expo start` запускается.
```

**0.2 Git и окружение** — `git init`, `.gitignore`, `.env` из `.env.example`, репозиторий на GitHub (приватный).

## Фаза 1. Дизайн-система и навигация (неделя 1)

**1.1 Базовые компоненты**
```
По @docs/DESIGN.md и @src/theme/tokens.ts создай компоненты в src/components:
Button (primary/secondary/ghost, объёмная «подошва», анимация нажатия Reanimated + haptic),
Chip (плитка слова с анимацией pop), ProgressBar (анимированный рост), Card, IconButton,
BottomSheet (выезд снизу на spring), Ring (круговой прогресс цели дня).
Подключи шрифты Bricolage Grotesque и Manrope. Сделай экран app/dev/components.tsx
для просмотра всех компонентов. Учитывай reduce motion.
```

**1.2 Навигация** — вкладки `(tabs)`: Учиться, Диалог, Прогресс, Профиль; модальные стеки `(lesson)` и `(onboarding)`; заглушки экранов.

## Фаза 2. Движок уроков (недели 2–3) — сердце продукта

**2.1 Схема контента**
```
По @docs/CURRICULUM.md создай Zod-схемы урока и всех типов упражнений в
src/features/lesson/schema.ts и загрузчик JSON из папки content/. Добавь 3 тестовых урока A1.
```

**2.2 Плеер урока**
```
Создай экран app/(lesson)/[id].tsx: прогресс-бар, рендер упражнения по типу,
кнопка «Проверить», нижний лист результата (успех/ошибка) с анимациями из
@.cursor/rules/10-design.mdc, звуки и haptic. Ошибочные упражнения повторяются в конце урока.
Реализуй типы: select_translation, build_sentence, listen_select, match_pairs, fill_gap, type_translation.
Логику проверки ответов вынеси в src/features/lesson/grading.ts и покрой тестами Jest.
```

**2.3 Итог урока** — экран с конфетти (Lottie), XP, точностью, новыми словами.

## Фаза 3. Бэкенд и прогресс (неделя 4)

**3.1 Supabase**
```
Создай SQL-миграции в supabase/migrations: profiles (уровень, цель, минут в день, вариант испанского),
lesson_progress, review_cards (поля FSRS), xp_events, streaks, chat_sessions, ai_usage.
Включи RLS: пользователь видит только свои строки. Подключи клиент в src/lib/supabase.ts,
авторизацию через Apple, Google и email (magic link), плюс анонимный вход для старта без регистрации.
```

**3.2 Путь и серия** — экран «Учиться» как на макете: змейка узлов, пульсирующий текущий узел, цель дня, расчёт серии с «заморозкой».

**3.3 Офлайн** — кэш контента блока и очередь синхронизации прогресса.

## Фаза 4. Повторения FSRS (неделя 5)
```
Реализуй интервальные повторения на ts-fsrs: каждое новое слово из урока создаёт карточку,
экран app/(lesson)/review.tsx с самооценкой (Снова/Трудно/Хорошо/Легко), счётчик «повторить сегодня»
на экране Прогресс. Ошибки из уроков тоже попадают в повторения.
```

## Фаза 5. Онбординг и подписка (неделя 6)

**5.1 Онбординг** — 5 шагов из @docs/DESIGN.md, мини-урок как вау-момент, запрос уведомлений после первого урока (не на старте).

**5.2 RevenueCat**
```
Подключи react-native-purchases. Entitlement `plus`, продукты: годовой с 7-дневным триалом и месячный.
Экран пейвола как на макете (годовой выделен). Хук useIsPlus(). Ограничения бесплатного плана:
доступ к A1 полностью, далее 1 блок в неделю, 3 ИИ-диалога в неделю. Кнопка «Восстановить покупки».
```

## Фаза 6. ИИ-собеседник (недели 7–8)

**6.1 Edge Function**
```
Создай supabase/functions/tutor-chat по правилам @.cursor/rules/20-content.mdc: вызов LLM,
строгий JSON-ответ, проверка лимитов по ai_usage и entitlement, логирование токенов.
Создай supabase/functions/grade-answer для свободных ответов.
```

**6.2 Экран диалога** — как на макете: пузыри, жёлтые карточки исправлений, чипы-подсказки, перевод по тапу, 10 сценариев A1–A2.

**6.3 Голос** — запись, распознавание и оценка произношения (Edge Function `speech-assess`), упражнение `speak_repeat`, голосовой ввод в диалоге.

## Фаза 7. Аналитика, уведомления, полировка (неделя 9)
- PostHog: события из @.cursor/rules/30-code-quality.mdc, воронка онбординг → урок → пейвол → триал.
- Sentry, экран ошибок сети.
- Локальные уведомления: напоминание в выбранное время, «серия под угрозой».
- Тёмная тема, i18n (русский + английский), проверка доступности.

## Фаза 8. Релиз (неделя 10)
- EAS Build и EAS Submit, TestFlight и закрытое тестирование Google Play (Google требует тестировщиков перед публикацией для новых личных аккаунтов — заложите 2 недели).
- Политика конфиденциальности и условия (обязательны для подписок), удаление аккаунта в приложении.
- ASO: название с ключом («Vamos: испанский язык»), 6–8 скриншотов с подписями, превью-видео.
- Бета на 50–100 человек, сбор отзывов, исправления.

## После MVP: дорожная карта
| Месяц | Что |
|---|---|
| 3–4 | Уровень B1, «умное чтение», истории с аудио, виджет серии |
| 5–6 | B2, лиги и друзья, веб-версия для оплаты мимо магазина (web2app) |
| 7–9 | C1, письмо с разбором ИИ, тесты в формате DELE |
| 10–12 | C2, интерфейс на английском и других языках (рынок шире в 10+ раз) |

## Метрики, за которыми следить с первого дня
- Retention D1 / D7 / D30 (ориентир: 40% / 20% / 10% и выше)
- Конверсия установка → триал и триал → оплата
- Доля завершивших первый урок в онбординге
- Стоимость ИИ на платящего пользователя в месяц
