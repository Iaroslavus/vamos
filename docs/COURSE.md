# Vamos — курс от нуля до B2

Этот документ — методика и устройство курса. Конкретное содержание:

- `docs/COURSE-A1.md` — A1 поурочно (12 модулей, 20 тем, 61 урок, 373 фразы и слова);
- `docs/COURSE-A2-B2.md` — A2, B1, B2 по темам (31 модуль, 56 тем, ~171 урок в плане);
- `content/course-plan.json` — то же самое в машиночитаемом виде, вход для контент-пайплайна;
- `docs/COURSE-PROMPTS.md` — задачи для Cursor по внедрению.

Вариант языка — **Испания (es-ES)**: vosotros, θ в «cena/zumo», «vale», «zumo», «piso», «móvil». Отличия Латинской Америки показываются пометкой 🌎 в заметке к фразе (jugo, celular, departamento, ustedes вместо vosotros, seseo). Озвучка — испанский голос; латам-вариант озвучки — позже.

## 1. Принципы

1. **Ситуация, а не грамматика.** Каждый урок отвечает на вопрос «что я смогу сказать сегодня в реальной жизни». Грамматика объясняется после того, как фразы уже звучат.
2. **Сначала фраза, потом разбор.** ≥ 80% единиц на A1 — готовые фразы (в плане 333 из 373). Слова появляются внутри фраз и через чипы «из чего состоит».
3. **Знакомство перед проверкой.** Новая единица всегда сначала показывается (intro: звук, перевод, разбор), и только потом тестируется.
4. **Говорить с первого дня.** В каждом уроке есть шаг «Скажи вслух»; в конце темы — диалог-сценка.
5. **Маленькие порции.** Урок — 6–7 единиц, 5–7 минут. Тема — 2–4 урока. Модуль — неделя-полторы.
6. **Повторение решает.** Всё пройденное уходит в FSRS; «Сегодня» сначала даёт повторение, потом новое.
7. **Честный уровень.** Чекпоинты в формате DELE показывают реальный прогресс, а не только «стрик».

## 2. Структура

```
Уровень (A1…B2)
 └─ Модуль (unit): 1–3 темы + карточки «Основи» + звуки + иногда чекпоинт
     └─ Тема (topic): ситуация, can-do, 2–4 урока, сценка
         └─ Урок (lesson): 6–7 items → шаги intro → recognize → build → recall → speak → dialog
```

Три дорожки в приложении:

| Дорожка | Где в UI | Что внутри | Обязательна? |
|---|---|---|---|
| **Ситуации** | Темы | Основной путь: темы и уроки по порядку | Да |
| **Основи** | Внутри темы, после 1-го урока + отдельный список в профиле | Короткие карточки грамматики 3–5 мин: правило в 2 фразах, 3 примера из уже пройденных уроков, 5 упражнений | Рекомендуется, не блокирует |
| **Звуки** | Карточка в «Сегодня» + список | 8 мини-уроков 2–3 мин по произношению, с проверкой микрофоном | По желанию, предлагается при ошибках |

Если пользователь ошибается в звуке (например, h или rr) — приложение предлагает соответствующий мини-урок звуков.

## 3. Шаблон темы

1. **Урок 1–N** (по 6–7 items): генератор строит шаги intro → recognize → build → recall → speak → dialog.
2. **Карточка «Основи»** модуля появляется после первого урока темы, где встречается правило.
3. **Сценка темы**: 6–10 реплик, пользователь отвечает голосом или выбором, использует только фразы этой и прошлых тем.
4. **Итог темы**: «Теперь вы умеете…» (can-do списком) + кнопка «Добавить в словник».

## 4. Объём и время

| Уровень | Модулей | Тем | Уроков | Словарь (активный+пассивный) | Время с повторениями |
|---|---|---|---|---|---|
| A1 | 12 | 20 | 61 | 700–900 | 90–100 ч |
| A2 | 12 | 20 | ~60 | ~1500 | до 180–200 ч накопительно |
| B1 | 10 | 20 | ~60 | ~3000 | до 350–400 ч |
| B2 | 9 | 16 | ~51 | ~5000 | до 500–600 ч |

Часы — ориентир по CEFR/Instituto Cervantes для уверенного учащегося, включая повторения и практику вне приложения. В маркетинге не обещаем «B2 за 3 месяца».

При 15 мин в день: A1 ≈ 3–4 месяца, A2 ≈ ещё 4–5, B1/B2 — заметно дольше, и там приложение должно дополняться разговорной практикой (репетитор, AI-ролевые сценки).

## 5. Как меняется формат по уровням

| | A1 | A2 | B1 | B2 |
|---|---|---|---|---|
| Единица урока | короткая фраза | фраза + вариант | фраза-шаблон с пропусками | связка / аргумент |
| Сценка | 6–8 реплик, выбор + голос | 8–10 реплик, голос | открытый ответ голосом | мини-дебат, монолог 1 мин |
| Аудирование | фраза | диалог 20–30 с | диалог 1 мин | новость / подкаст 2 мин |
| Чтение | ценники, меню | сообщения, объявления | письмо, статья | статья, мнение |
| Письмо | — | короткое сообщение | e-mail, жалоба | эссе 150–180 слов |
| Оценка | правильно / нет | правильно / нет | ИИ-фидбек (позже) | ИИ-фидбек по критериям DELE |

Открытые ответы (письмо и говорение B1–B2) требуют ИИ-проверки — это отдельная фича, пока не делаем; до неё B1–B2 строятся на фразах-шаблонах и выборе.

## 6. Чекпоинты

| ID | Когда | Формат |
|---|---|---|
| `cp.a1.week1` | день 7 | Сценка «Первый разговор», без оценки |
| `cp.a1.final` | после A1-U12 | Мини-DELE A1: аудирование, чтение, письмо, говорение; порог 60% |
| `cp.a2.final` | после A2-U12 | Мини-DELE A2 |
| `cp.b1.final` | после B1-U10 | Мини-DELE B1 |
| `cp.b2.final` | после B2-U09 | Мини-DELE B2 + рекомендации к реальному экзамену |

Чекпоинт не блокирует следующий уровень, но результат показывается в профиле, а слабые темы попадают в «Повторить».

## 7. Материалы репетитора

- Оригиналы файлов репетитора **не кладём в публичный репозиторий** (авторское право + репозиторий публичный). Храним локально в `private/tutor/` (добавить в `.gitignore`).
- Из урока репетитора берём **ситуацию, фразы и грамматику**, сопоставляем с темой курса: если тема есть — фразы уходят в `overrides`/дополнительный урок; если нет — создаём пользовательскую тему или папку в словнике.
- Своими словами пишем объяснения и примеры, не копируем тексты и упражнения.

## 8. Контроль качества контента

1. `npm run content:check`: уникальные id, 5–7 items в уроке, ¿?/¡! в паре, есть перевод ru/uk/en, нет `draft` в релизе.
2. Переводы uk/en генерирует пайплайн из ru + es, потом выборочная вычитка.
3. **Ревью носителем** каждого модуля перед релизом (особенно ударения, естественность фраз, пометки 🌎). Пока ревью нет — `draft: true`.
4. Озвучка: Azure Neural (es-ES), нормальная и медленная (-25%); после генерации — прослушать 10% выборочно.

## 9. Порядок внедрения

1. Схема и импорт плана (COURSE-PROMPTS: C1–C2) — сохранить существующие id тем A1.
2. Генерация недостающих тем A1 (C3) → ревью → озвучка.
3. «Основи» и «Звуки» в UI (C4–C5).
4. Чекпоинты (C6).
5. A2 пакетами по 2 модуля (C7), затем B1, B2.
